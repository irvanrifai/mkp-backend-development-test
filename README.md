# Backend Development Test Mitra Kasih Perkasa (MKP)

Oleh: Irvan Rifa'i

Repositori ini berisi implementasi backend tiket bioskop dalam arsitektur clean layered menggunakan Golang.

## Struktur Utama

* `api-ticketing/` - Backend service utama dengan handler HTTP, usecase, repository, models, dan mock tests.
* `database-design/` - Dokumentasi desain dan strategi database PostgreSQL.
* `system-design/` - Ringkasan arsitektur sistem dan keputusan desain teknis.

## Catatan

Silakan buka `api-ticketing/README.MD` untuk instruksi setup, migrasi, dan workflow pengembangan.
